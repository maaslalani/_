# Memory

## Code

- Follow the local pattern; offer helpers as options.
- Minimal diffs: dedupe behaviour, not lines; delete unreachable code.
- List cuts that cost behaviour as numbered options.
- Enums over strings, unless local code uses strings.
- Short, lowercase conventional commits.
- No Python.

## Communication

- Ask when ambiguous.
- After pushing a PR, stop; don't poll CI.

## Visuals

- I prefer visualizations, only when text can't show it.
- Always prefer HTML.
- SVG, rendered with `resvg --zoom 2`.
- Minimal: few colors, one font size, bold for emphasis.
- JetBrains Mono, Iosevka fallback.
- Numbered options for subjective choices.
- Use typst when appropriate (typeset documents, PDFs, math, tables).

## Design

- Grid-aligned, generous whitespace (Swiss).
- Function first, no decoration (Rams).
- Dense data, direct labels, small multiples (Tufte).
